# Проверка первого комплекта 70532

Первый комплект предназначен для проверки установки и локального **базового
Forever**, не для теста ещё не перенесённого режима Hordes. Сборка 70532
экспериментальная. Проверку забега Hordes нельзя отмечать пройденной на этом этапе.

Перед началом: Windows x64, Docker Desktop с Linux containers,
WebView2 Runtime (обычно уже есть в Windows 11), полностью обновлённый клиент
1.60.1.70532. Если WebView2 отсутствует, установите его с
[официальной страницы Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
Основная [инструкция установки](LAUNCHER.ru.md).

| Проверка | Ожидаемый результат |
|---|---|
| Открыть HordesForeverSetup.exe | Русское окно установщика, без Python или SDK на компьютере |
| Установить компоненты из GitHub | Блоки проходят SHA-256, образы загружаются локально, версия активируется после полной установки |
| Повторить установку той же версии | Нет перезаписи клиента, сертификатов и сохранений |
| Выбрать корень клиента 70532 | Активная версия читается из .build.info |
| Указать другой клиент | Подготовка прекращается с сообщением о несовпадении версии |
| Запустить движок впервые | Создаются локальные сертификаты, извлекаются данные; после завершения импорта worldserver готов к подключению |
| Создать локальный аккаунт | Команда bnetaccount create в консоли завершается успешно |
| Нажать «Войти в игру» | Открывается окно игрового лаунчера; подготовка ПК устанавливает локальный адрес и CA |
| Войти и создать персонажа | Вход в мир; проверить обе разновидности Skyborne в стандартном создании персонажа |
| Проверить бой и квест | Перемещение, цель, обычная атака, способность и завершение доступного квеста |
| Выйти, остановить и снова запустить движок | Персонаж, позиция и полученный прогресс сохранились |
| Повторить запуск без интернета | После полной первичной подготовки вход работает через localhost; загрузка компонентов не требуется |

Проверяйте по порядку. Не останавливайте первый импорт базы. Открытый порт,
запущенный контейнер или окно входа не подтверждают успех последующих пунктов.
Если создание Skyborne отсутствует или отклоняется сервером, запишите конкретную
фракцию, класс и текст ошибки; это ещё не подтверждённая игровая возможность.

При ошибке нужны номер версии пакета, шаг из таблицы, текст сообщения и время
воспроизведения. Журнал движка доступен кнопкой в установщике. Перед отправкой
фрагмента журнала уберите почту, пароли и приватные сообщения. Папки `profile`,
`game-settings`, закрытые ключи и целую базу для диагностики не отправляйте.

Подтверждённые автоматически проверки перечисляются отдельно: unit-тесты,
проверка конфигурации Compose, сборка Windows EXE, запуск его окна на Windows.
Они не заменяют вход в мир и перечисленные игровые проверки на вашем клиенте.
